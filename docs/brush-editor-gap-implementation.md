# Brush editor gap implementation

October 31, 2026. Follows `brush-editor-screenshot-gap-audit.md`. This delivery covers the pictured gaps in Grain, Properties, Taper, Stabilization and Shape. Existing native Stroke Path controls remain reused. The supplied screenshots establish controls and visible examples; numeric archive mappings and proprietary equations are not inferred.

## Native behavior

- **Grain:** optional native texture, custom image or owned original embedded grain. The existing bounded mask decoder/import budget and original-byte store are shared with Shape. Refresh Mapping re-reads older imports to derive their embedded grain. Original grain remains required until the user explicitly configures native grain; missing originals cannot be selected as available. Secondary-component grain remains gated.
- **Sampling:** Texturized repeats in document coordinates; Moving samples around the tip and advances texture phase along stroke distance. Movement controls this phase advance. Scale uses document pixels; Zoom blends fixed scale toward brush diameter. Rotation transforms texture axes. Texturized also caps accumulated per-pixel stroke coverage so repeated full-flow overlaps retain the texture; Moving deposits per dab and can build up. Depth modulates deposited coverage, depth/offset jitter reuse the stroke seed (fixed per Texturized stroke, varying per Moving dab), brightness/contrast modify the grain before compositing. Native Multiply, Screen, Overlay and Subtract variants act inside the primary silhouette. None/Classic/Improved use nearest, wrapped bilinear, or four-sample filtering. Imported textures repeat as supplied; tile seams in a nonseamless source are not removed by fabricating missing pixels. Native Woven Texture is a cached, periodic mathematical image, not a bundled/downloaded Procreate asset.
- **Properties:** size bounds are document pixels (1–2000); opacity bounds are normalized 0–1, with maximum at least 1%. Invalid minimum/maximum ordering disables Save. Stroke construction clamps current diameter/opacity; pressure response respects size/opacity floors without multiplying the maximum opacity twice. Taper can deliberately reach zero beyond these pressure floors. Rendering alpha threshold still runs afterward and can intentionally quantize coverage to full opacity. Orient to Screen uses document/screen axes; off adds layer rotation to tip orientation. The current canvas has no separate rotating view. Smudge Pull scales Smudge strength only; zero transfers no pigment, and Liquify is unchanged.
- **Taper:** separate optional pen and mouse/touch groups selected by actual pressure-channel presence. Each has start/end lengths as fractions of completed distance, linked endpoints, size/opacity amount and Tip easing. Pen Pressure modulates the response through the brush pressure curve. Existing legacy size taper remains compatible and multiplies native size taper when both are present. Classic uses a linear ramp; otherwise Tip changes its exponent (0.25–4). Tip Animation adds provisional taper while drawing; final replay always resolves against completed length. Final replay restores all coverage/pigment/edge state as before.
- **Stabilization:** optional StreamLine position tracking and pressure low-pass; separate position damping; Motion Filtering screen-space deadband; Expression relaxes damping/deadband during larger input movements. Existing trailing-string Smoothing reuses the tracking helper and retains its defaults. These native responses are sample based, so their feel varies with event cadence; hardware-dependent tuning remains exposed. Finish catches up to the final pointer. Preview and canvas both use EditorSession's input path.
- **Shape:** enlarged inspection shows the exact derived mask used by painting, including dimensions and the existing 256 px resource bound. No automatic loading of giant source images. New Relative to Stroke adds path heading to azimuth/barrel orientation. Legacy initial-barrel-relative metadata remains honored. Scatter is now displayed as 0–100% corresponding to ±0–180°, preserving stored radians.

All new groups are optional preset metadata, validated before storage/painting. Missing groups preserve legacy defaults. No `.comp` schema change: documents retain painted pixels through their existing raster representation. No new dependency, source image bundle, or guessed imported setting mappings.

## Scope boundaries

Preview Size/Source Preview Settings, independent secondary dynamics/grain, Wet Mix, Color Dynamics, remaining Dynamics controls and source-only 3D Materials were not part of the confirmed screenshot gaps. Their existing unavailable controls remain labeled. The enlarged inspector does not claim to recover detail already lost by bounded downsampling. Source-equivalent feel, physical Wacom/Apple Pencil acceptance and release latency are separate from automated native behavior checks.
